## Chicago Crime Text-to-SQL

**Paper:** An Iterative LangGraph Agent for Text-to-SQL: Natural Language Access to the Chicago Crime Database

**Authors:** Vigneshwar Ravi Rao, Rupesh Swarnakar, and Fayeq Jeelani Syed.

**Overview:** An empirical evaluation of two LangGraph pipelines for querying the Chicago Crime database in natural language. The study examines prompting, relevance filtering, SQL validation and retry, and answer synthesis, distinguishing executable SQL from correct query results and faithful natural-language answers.

### Code and resources

- **Code repository:** [Vigneshwarr3/chicago-text2sql](https://github.com/Vigneshwarr3/chicago-text2sql)
- **Database snapshot:** Docker image `vigneshwarr/chicago-crime-db`
- Consult the project repository for setup instructions, benchmark questions, evaluation code, and supporting materials.
